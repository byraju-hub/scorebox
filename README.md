# ScoreBox 악보함

악보 이미지/PDF를 **코드(Key) · 빠르기(빠른/보통/느린) · 주제(태그)** 로 정리하는 로컬 웹 앱입니다.
Python 3.8+ 만 있으면 되고 추가 설치는 필요 없습니다.

## 설치 없이 쓰기 (Python 불필요): scorebox.html
Chrome(또는 Edge)에서 `scorebox.html` 을 열고 **악보 폴더 선택**을 누르세요.
- 분류 정보는 선택한 폴더의 `scorebox_data.json` 에 저장됩니다 (아래 Python 버전과 같은 형식이라 서로 이어서 쓸 수 있음).
- 다음에 열 때는 "폴더 열기" 버튼을 한 번 눌러 접근을 허용하면 됩니다.
- Chrome 이 막는 폴더(예: Documents, Downloads 자체)는 그 안의 하위 폴더를 선택하세요.
- 업데이트: `scorebox.html` 파일만 새 것으로 교체하면 됩니다.

## Python 버전 실행
`start.bat` 더블클릭 → 브라우저가 자동으로 열립니다 (http://127.0.0.1:8765).

## 설정 (`config.json`)
- `scores_dir`: 악보 파일이 있는 폴더 (하위 폴더까지 검색). 원본 파일은 수정/이동하지 않습니다.
- `data_file`: 분류 정보 저장 파일(JSON). OneDrive 폴더 안에 두면 자동 백업/동기화됩니다.
  현재 설정: `"C:/Users/byraj/Pictures/scorebox_data.json"`
- 프로그램 폴더 자체를 OneDrive 안에 두어도 됩니다.

## 업데이트
`update.bat` 더블클릭 (git 으로 받은 경우). ZIP 으로 받은 폴더는 git 저장소가 아니라 동작하지 않습니다.

## 사용법
1. 처음 실행하면 폴더를 스캔하고 **파일명에서 코드/빠르기를 자동 추정**합니다
   (예: `은혜_G_느린.pdf`, `Amazing Grace - D.jpg`). 하위 폴더 이름은 주제 태그가 됩니다.
2. 추정된 곡은 "확인 필요" 표시가 붙습니다. 카드를 눌러 확인/수정 후 **저장 후 다음 ▶** 로 빠르게 넘기세요.
3. 여러 곡을 체크박스로 선택하면 코드/빠르기/태그를 한 번에 지정할 수 있습니다.
4. 왼쪽 필터(코드·빠르기·태그)와 검색으로 곡을 찾습니다. 새 파일을 추가하면 "폴더 다시 스캔".
5. "엑셀(CSV) 내보내기"로 전체 목록을 받을 수 있습니다.

## 콘티 (찬양 콘티 만들기 · 인쇄 · JPG)  — scorebox.html
왼쪽 위 **📋 콘티** 탭에서 사용합니다.
- **📥 콘티 가져오기**: 저장소의 `contis.json` (2023~2026 콘티 261개, 1,377곡)을 불러옵니다. 한 번만 하면 `scorebox_data.json` 에 저장됩니다.
- 콘티를 고르면 곡 순서·악보 파일(코드)을 바꾸고, **＋ 곡 추가**로 악보함에서 곡을 골라 넣을 수 있습니다. 곡마다 사용 횟수/마지막 사용일이 보입니다. 변경은 자동 저장됩니다.
- **🖨 인쇄 · JPG 만들기**: B4 / A3 / A4, 한 면 2칸(가로·양면) 또는 1칸(세로). 짧은 곡은 한 칸에 쌓이고, 후렴은 **자르기**로 일부만 넣고 빨간 라벨을 달 수 있습니다.
  - **🖨 인쇄**: 브라우저 인쇄 창에서 *여백 없음 · 배율 100% · 양면 인쇄*로 출력하세요.
  - **💾 JPG로 저장**: 악보 폴더의 `콘티출력` 폴더에 면마다 JPG 한 장씩 저장합니다 (악보 목록에는 나타나지 않음).
- 이미지 악보(jpg/png 등)만 배치할 수 있습니다. PDF 악보는 이미지로 변환해야 합니다.
