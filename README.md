# Raju's ScoreBox

악보 이미지/PDF를 **코드(Key) · 빠르기(Speed) · 카테고리(Tag)** 로 정리하고, **찬양 콘티**를 만들어 B4/A3/A4로 인쇄하거나 JPG로 저장하는 로컬 웹 앱입니다.
설치가 필요 없고 서버도 없습니다. **Chrome(또는 Edge)에서 `scorebox.html` 을 열면 됩니다.**

## 설치
설치 프로그램이나 서버는 필요 없습니다. 파일만 내려받아 `scorebox.html` 을 열면 됩니다. **Windows + Chrome(또는 Edge)** 기준입니다.

### 방법 1. ZIP으로 받기 (가장 간단)
1. https://github.com/byraju-hub/scorebox 에서 초록색 **Code** 버튼 → **Download ZIP** 을 누릅니다.
2. 받은 ZIP 의 압축을 풉니다 (예: `C:\Users\내이름\Projects\ScoreBox`). 압축을 푼 폴더는 지우거나 옮기지 마세요.
3. 폴더 안의 `scorebox.html` 을 **Chrome 또는 Edge** 로 엽니다 (더블클릭 또는 브라우저로 끌어놓기).
4. 아래 **시작하기**대로 악보 폴더를 선택합니다.
- 업데이트: 새 버전이 나오면 ZIP 을 다시 받아 같은 폴더에 덮어씁니다. 분류 정보는 악보 폴더의 `scorebox_data.json` 에 있으므로 지워지지 않습니다.

### 방법 2. Git으로 받기 (업데이트가 쉬움)
1. [Git for Windows](https://git-scm.com/download/win) 를 설치합니다.
2. 원하는 위치에서 PowerShell 을 열고 아래 명령으로 받습니다.
   ```
   git clone https://github.com/byraju-hub/scorebox.git
   ```
3. 받은 `ScoreBox` 폴더의 `scorebox.html` 을 Chrome 또는 Edge 로 엽니다.
4. 업데이트는 폴더의 `update.bat` 을 더블클릭하면 됩니다 (아래 **업데이트** 참고).

### 확인할 점
- **Chrome / Edge 만 지원**합니다 (폴더 접근 기능이 필요합니다). Firefox, Safari 는 안 됩니다.
- 악보 이미지와 분류 데이터는 **각자 PC 의 악보 폴더에만** 저장되고, GitHub 나 인터넷으로 올라가지 않습니다.
- 악보 파일은 수정하지 않고 읽기만 합니다 (콘티 JPG 는 악보 폴더 안 `콘티출력` 폴더에 저장).
- 폴더 접근 허용 창이 뜨면 **"이 사이트를 방문할 때마다 허용"** 을 고르면 다음부터 폴더가 자동으로 열립니다.

## 시작하기
1. Chrome에서 `scorebox.html` 을 열고 **악보 폴더 선택**을 누릅니다 (예: `Pictures`). 하위 폴더까지 읽고, 원본 파일은 수정하지 않습니다.
2. 접근 허용 창이 뜨면 허용합니다. 다음에 열 때는 **폴더 열기** 버튼을 한 번 눌러 접근을 허용하세요.
3. 분류 정보와 콘티는 선택한 폴더의 `scorebox_data.json` 에 자동 저장됩니다. 가끔 다른 곳에 복사해 백업해 두세요.
- Chrome 이 막는 폴더(Documents, Downloads 자체 등)는 그 안의 하위 폴더를 선택하세요.

## 업데이트
`update.bat` 더블클릭 (**방법 2 로 받은 폴더에서만** 동작하며 Git 설치가 필요합니다. ZIP 으로 받았다면 ZIP 을 다시 받아 덮어쓰세요). 앱이 열려 있으면 Chrome 에서 Ctrl+F5 를 누르세요. `scorebox_data.json` 은 건드리지 않습니다.

## 악보함
- 처음 스캔하면 파일명에서 코드를 추정하고(`G_은혜.png`, `Am 주님.jpg`), 하위 폴더 이름은 카테고리(Tag)가 됩니다. 추정된 곡은 **⚠ 확인 필** 로 표시됩니다. 새 악보를 폴더에 넣은 뒤에는 **📁 폴더 다시 스캔**(또는 앱을 다시 열기)으로 추가됩니다.
- **확인하기**: 카드를 눌러 고치고 **저장 후 다음 ▶**, 또는 **⚠ 확인 필** 칩을 켠 뒤 위쪽 **✓ 보이는 N곡 모두 확인 완료**로 한꺼번에 처리합니다.
- **찾기·분류**: 왼쪽의 코드(Key) · 빠르기(Speed) · 카테고리(Tag) 칩으로 걸러 보고(하나씩 선택), **전체 악보 보기**로 필터를 모두 풀 수 있습니다. 검색은 제목·파일명·카테고리·메모를 함께 찾습니다. 투명 배경 악보는 흰색 배경 위에 보여 줍니다.
- **선택**: 체크박스 / **☑ 전체 선택** 으로 고른 뒤 파란 막대에서 코드·빠르기·카테고리 일괄 지정, 확인 완료/되돌리기, 목록에서 제외(복원 가능), 파일 삭제(악보 폴더의 `_삭제된악보` 폴더로 옮김), **바구니에 담기**를 할 수 있습니다.
- **🧺 콘티 바구니**: 카드 오른쪽 아래 주황색 바구니 버튼(또는 악보 상세 창의 버튼)으로 콘티에 쓸 곡을 미리 담아 둡니다. 담긴 카드는 주황색 테두리로 표시되고, 위쪽의 **바구니 비우기**로 한 번에 비웁니다. 바구니는 콘티 탭에서 이어서 씁니다.
- **악보함 도구 모음**(왼쪽 아래): 📁 폴더 다시 스캔 · 📂 폴더 바꾸기 · 🕊 찬양 추천 · ⚙ 코드(Key) 설정 · ⚙ 빠르기(Speed) 설정 · ⚙ 카테고리(Tag) 설정 · ⬇ 엑셀(CSV) 내보내기 · 🗂 백업 · 복원 · 🧩 중복 곡 정리 · 🎼 찬송가/CCM 분류. 설정 버튼에서는 항목을 추가·이름 변경·삭제·순서 변경하고, 파일명 자동 인식 키워드를 정할 수 있습니다.
- **🕊 찬양 추천**: 성경 본문을 고르면 AI(Claude Haiku)가 어울리는 찬양을 추천합니다. 사용하려면 먼저 아래 **찬양 추천 설정**을 한 번 해 두세요.
- **🧩 중복 곡 정리**: 제목(숫자 제외)과 코드가 같은 곡을 묶어 보여 주고, 하나만 남기고 나머지를 제외하거나 삭제합니다. 카테고리·메모·빠르기는 남기는 곡에 합쳐지고 콘티의 악보도 바뀝니다. 중복이 아니면 **중복 아님**으로 표시합니다.
- **🕘 최근 사용 표시**: 최근 28일 안에 콘티에 쓴 곡은 카드에 `🕘 3일 전`, 앞으로의 콘티에 들어 있는 곡은 `📅 10/12 예정` 배지가 붙어 같은 곡이 너무 자주 겹치지 않게 볼 수 있습니다.
- **🗑 파일 삭제**: 파일을 지우지 않고 악보 폴더 안 `_삭제된악보` 폴더로 옮깁니다(하위 폴더 구조 그대로). 되살리려면 그 폴더에서 원래 위치로 옮긴 뒤 **폴더 다시 스캔**을 누르세요. 완전히 지우려면 그 폴더를 직접 비우면 됩니다.
- **이름을 바꾸거나 옮긴 파일**: 스캔할 때 사라진 파일과 새 파일의 크기·확장자가 같으면 같은 악보로 보고, 기존 분류·메모·콘티·바구니 연결을 이어 갈지 물어봅니다. (이 기능이 생기기 전에 스캔된 파일은 다음 스캔부터 적용됩니다.)
- **🎼 찬송가/CCM 분류**: 찬송가 목록 JSON(제목이 들어 있는 `[{ "number": 1, "title": "…" }, …]` 형식)을 올리면, 제목이 일치하거나 파일명 끝에 찬송가 번호(2~3자리, 645 이하)가 있는 곡에는 **찬송가**, 나머지에는 **CCM** 카테고리를 붙입니다. 적용 전에 미리보기로 개수를 확인하고, 이미 붙은 곡은 건너뜁니다. 찬송가 목록은 한 번 올리면 저장됩니다.
- 카드 크기 슬라이더, 검색, 엑셀(CSV) 내보내기가 있습니다.

## 백업 · 복원
분류·메모·콘티·바구니·휴지통은 모두 악보 폴더의 `scorebox_data.json` 하나에 들어 있습니다. 이 파일을 **ScoreBox 프로그램 폴더의 `backup` 폴더**에 자동으로 백업해 둘 수 있습니다.
1. **악보함 도구 모음 → 🗂 백업 · 복원 → 📂 백업 폴더 지정** 에서 ScoreBox 프로그램 폴더(예: `C:\Users\내이름\Projects\ScoreBox`)를 고릅니다. 그 안에 `backup` 폴더가 만들어집니다(`backup` 폴더를 직접 골라도 됩니다).
2. 그 뒤로는 앱을 열 때 **하루에 한 번** `scorebox_data_2026-10-10.json` 처럼 자동 백업되고, 최근 30개만 남깁니다. **💾 지금 백업**으로 언제든 직접 백업할 수 있습니다.
3. 복원은 같은 창의 목록에서 **이 백업으로 복원**을 누르면 됩니다. 복원 직전의 데이터도 `…_before_restore.json` 으로 먼저 백업됩니다.
- `scorebox_data.json` 이 망가져 앱이 열리지 않으면 시작 화면에 **🗂 백업에서 복원** 버튼이 나타나 가장 최근 백업으로 되돌릴 수 있습니다.
- Chrome 이 백업 폴더 접근을 다시 물으면 허용해 주세요("방문할 때마다 허용"을 고르면 다음부터 묻지 않습니다). `backup` 폴더는 GitHub 로 올라가지 않습니다(`.gitignore`).

## 찬양 추천 설정 (AI)
**🕊 찬양 추천**은 성경 본문(책 · 장 · 절)을 고르면 그 말씀에 어울리는 찬양을 추천해 줍니다. 악보함에 있는 곡은 **🧺 담기 / 악보 보기** 버튼으로 바로 쓰고, 악보함에 없는 곡(한국어 찬송가·CCM 위주)은 제목과 이유, **악보 검색 · YouTube** 링크로 보여 줍니다.

**처음에 한 번만 준비하세요.** 아래 두 파일을 **악보 폴더**(악보가 들어 있는 폴더, 예: `Pictures`) 맨 위에 넣습니다.
1. **`claude_api_key.txt`** — AI(Anthropic Claude) API 키 한 줄만 적은 텍스트 문서입니다.
   - [Anthropic Console](https://console.anthropic.com/) 에서 계정을 만들고 **API 키**를 발급받습니다 (사용한 만큼 요금이 청구됩니다).
   - 메모장에 키(`sk-ant-...`)만 붙여 넣고, 파일 이름을 `claude_api_key.txt` 로 저장합니다.
2. **`bible.json`** — 성경 본문 파일입니다. 책 이름·장·절·본문이 들어 있는 JSON 이어야 하며, 다음과 같은 형식을 읽습니다.
   - `{ "books": [ { "name": "창세기", "short": "창", "verses": [ { "chapter": 1, "verse": "1", "text": "태초에 …" } ] } ] }`
   - 그 밖에 책→장→절로 묶인 JSON, 절마다 `book / chapter / verse / text` 가 있는 목록, `"창1:1": "…"` 형식도 읽습니다. 성경 본문은 저작권이 있어 이 저장소에는 들어 있지 않으니 직접 준비하세요.

준비가 끝나면 **악보함 도구 모음 → 🕊 찬양 추천**에서 책 · 장 · 절을 고르고 **찬양 추천받기**를 누르면 됩니다. 한 번 넣어 두면 앱을 다시 열어도 매번 입력할 필요가 없습니다.

- 파일이 없으면 찬양 추천 창에 필요한 파일이 안내로 나옵니다. 이 두 파일은 악보로 스캔되지 않고 앱 목록에도 나타나지 않습니다.
- 추천 결과는 악보함 8곡 + 악보함 밖 5곡이며, 모델은 **Claude Haiku**(저렴·빠름)를 씁니다. 한 번에 드는 비용은 아주 적습니다(대략 수 원 수준, 악보함 곡 수에 따라 다름).
- **개인정보·보안**: 추천을 받을 때 **악보함 곡 제목 목록과 선택한 성경 구절**이 Anthropic 으로 전송됩니다(악보 이미지는 보내지 않습니다). API 키는 악보 폴더의 텍스트 파일에만 있으므로, 폴더를 다른 사람과 공유하거나 OneDrive 공유 폴더라면 키가 보일 수 있습니다. **키를 GitHub 나 채팅에 올리지 마세요.** 노출됐다면 Console 에서 키를 폐기하고 새로 발급받으세요.
- 받은 추천 결과는 `scorebox_data.json` 에 저장되어, **악보 보기**로 악보를 열었다 닫아도(추천 창은 그대로 남아 있습니다) 창을 닫았다 다시 열어도, 앱을 껐다 켜도 **마지막 추천 결과가 그대로 보입니다**. 새 추천을 받으면 그 결과로 바뀝니다.
- 추천은 AI 의 제안이라 곡 제목이 정확하지 않거나 악보가 없을 수 있으니, 콘티에 넣기 전에 확인하세요.

## 콘티 (찬양 콘티 · 인쇄 · JPG)
왼쪽 위 **📋 콘티** 탭에서 사용합니다. 콘티 목록은 15개씩 보이며 아래의 `« ‹ 1 2 3 › »` 와 페이지 선택으로 넘깁니다.

**콘티 도구 모음**(왼쪽): ＋ 새 콘티 · 📊 콘티 통계 · 📥 콘티 가져오기 · 🗑 콘티 휴지통, 그리고 🧺 콘티 바구니.
- **＋ 새 콘티 / 편집**: 날짜·예배 종류를 정하고 곡 순서·악보 파일(코드)을 바꿉니다. **＋ 곡 추가**로 악보함에서 곡을 고르며, 곡마다 사용 횟수/마지막 사용일이 보이고 바구니에 담은 곡이 맨 위에 먼저 나옵니다. 변경은 자동 저장됩니다. **텍스트 복사**는 `10/9 금요기도회 찬양입니다.` 와 `1. 곡명 (코드)` 형식으로 복사합니다.
- **📊 콘티 통계**: 많이 쓴 곡 순위, 오래 안 쓴 곡, 연도·월별 콘티 수, 예배 종류 비율, 코드·빠르기 분포를 기간·예배 종류로 걸러 보고, 표로도 볼 수 있습니다. 곡이나 콘티를 누르면 해당 콘티로 이동합니다.
- **📥 콘티 가져오기**: 콘티 JSON 파일(`contis.json` 형식)을 불러옵니다. 한 번만 하면 되고, 이미 있는 콘티는 건너뜁니다. (콘티 데이터는 공개 저장소에 두지 않고 각자 PC에서 관리합니다.)
- **🗑 콘티 휴지통**: 삭제한 콘티는 30일 동안 보관되고, 복원 · 완전 삭제 · 휴지통 비우기를 할 수 있습니다. 30일이 지나면 자동으로 완전히 삭제됩니다.
- **🧺 콘티 바구니**: 악보함에서 담은 곡을 ▲▼로 순서를 바꾸고, **바구니로 새 콘티 만들기**로 한 번에 콘티를 만듭니다.

**🖨 인쇄 · JPG 만들기** (콘티 편집 화면)
- **용지·배치**: 기본은 A3 · 가로 한 면에 2칸(양면) · 여백 6mm 입니다. B4 / A3 / A4, 한 면에 2칸 · **3칸**(가로·양면) 또는 1칸(세로)을 고를 수 있고, 설정은 저장됩니다.
- **곡 번호**: 악보마다 `(1)`, `(2)` 번호를 넣을 수 있습니다(끌 수 있음).
- **칸 지정**: 곡마다 *자동 / 새 칸에서 시작 / 위 곡과 같은 칸 / 1~6번 칸에 넣기* 를 고릅니다. 같은 칸에 여러 곡이 들어가면 곡 순서대로 채워집니다.
- **✂ 자르기**: 위·아래·왼쪽·오른쪽을 자르고 **크기(30~150%)** 를 조절합니다. 오른쪽의 **인쇄 미리보기**로 칸에서 얼마나 차지하는지 바로 확인합니다. 후렴은 일부만 넣고 빨간 라벨을 달 수 있습니다.
- **글꼴**: 머리글 · 곡 번호 · 라벨은 **고운 도담체(굵게)** 로 출력됩니다 (`fonts/` 폴더, OFL 라이선스).
- **🖨 인쇄**: 브라우저 인쇄 창에서 *여백 없음 · 배율 100% · 양면 인쇄*로 출력하세요.
- **💾 JPG로 저장**: 악보 폴더의 `콘티출력` 폴더에 **항상 A4 크기**로 저장합니다. 파일명은 `261009-1.jpg`(앞면), `261009-2.jpg`(뒷면) 형식(`YYMMDD-면`)이고, 같은 날짜에 콘티가 여러 개면 `250302a-1.jpg`, `250302b-1.jpg` 처럼 a·b 로 구분되며, 시트가 여러 장이면 `-3`, `-4` 로 이어집니다. 악보 목록에는 나타나지 않습니다.
- 이미지 악보(jpg/png 등)만 배치할 수 있습니다. PDF 악보는 이미지로 변환해야 합니다.
