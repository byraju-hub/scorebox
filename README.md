# ScoreBox 악보함

악보 이미지/PDF를 **코드(Key) · 빠르기(빠른/보통/느린) · 주제(태그)** 로 정리하는 로컬 웹 앱입니다.
Python 3.8+ 만 있으면 되고 추가 설치는 필요 없습니다.

## 실행
`start.bat` 더블클릭 → 브라우저가 자동으로 열립니다 (http://127.0.0.1:8765).

## 설정 (`config.json`)
- `scores_dir`: 악보 파일이 있는 폴더 (하위 폴더까지 검색). 원본 파일은 수정/이동하지 않습니다.
- `data_file`: 분류 정보 저장 파일(JSON). OneDrive 폴더 안에 두면 자동 백업/동기화됩니다.
  예: `"C:/Users/byraj/OneDrive/ScoreBox/scorebox_data.json"`
- 프로그램 폴더 자체를 OneDrive 안에 두어도 됩니다.

## 사용법
1. 처음 실행하면 폴더를 스캔하고 **파일명에서 코드/빠르기를 자동 추정**합니다
   (예: `은혜_G_느린.pdf`, `Amazing Grace - D.jpg`). 하위 폴더 이름은 주제 태그가 됩니다.
2. 추정된 곡은 "확인 필요" 표시가 붙습니다. 카드를 눌러 확인/수정 후 **저장 후 다음 ▶** 로 빠르게 넘기세요.
3. 여러 곡을 체크박스로 선택하면 코드/빠르기/태그를 한 번에 지정할 수 있습니다.
4. 왼쪽 필터(코드·빠르기·태그)와 검색으로 곡을 찾습니다. 새 파일을 추가하면 "폴더 다시 스캔".
5. "엑셀(CSV) 내보내기"로 전체 목록을 받을 수 있습니다.
