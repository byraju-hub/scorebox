# ScoreBox 악보함

악보 이미지/PDF를 **코드(Key) · 빠르기(Speed) · 카테고리(Tag)** 로 정리하고, **찬양 콘티**를 만들어 B4/A3/A4로 인쇄하거나 JPG로 저장하는 로컬 웹 앱입니다.
설치가 필요 없고 서버도 없습니다. **Chrome(또는 Edge)에서 `scorebox.html` 을 열면 됩니다.**

## 시작하기
1. Chrome에서 `scorebox.html` 을 열고 **악보 폴더 선택**을 누릅니다 (예: `Pictures`). 하위 폴더까지 읽고, 원본 파일은 수정하지 않습니다.
2. 접근 허용 창이 뜨면 허용합니다. 다음에 열 때는 **폴더 열기** 버튼을 한 번 눌러 접근을 허용하세요.
3. 분류 정보와 콘티는 선택한 폴더의 `scorebox_data.json` 에 자동 저장됩니다. 가끔 다른 곳에 복사해 백업해 두세요.
- Chrome 이 막는 폴더(Documents, Downloads 자체 등)는 그 안의 하위 폴더를 선택하세요.

## 업데이트
`update.bat` 더블클릭 (git 으로 받은 폴더에서만 동작). 앱이 열려 있으면 Chrome 에서 Ctrl+F5 를 누르세요. `scorebox_data.json` 은 건드리지 않습니다.

## 악보함
- 처음 스캔하면 파일명에서 코드를 추정하고(`G_은혜.png`, `Am 주님.jpg`), 하위 폴더 이름은 카테고리(Tag)가 됩니다. 추정된 곡은 **⚠ 확인 필요** 로 표시됩니다.
- **확인하기**: 카드를 눌러 고치고 **저장 후 다음 ▶**, 또는 **⚠ 확인 필요** 칩을 켠 뒤 위쪽 **✓ 보이는 N곡 모두 확인 완료**로 한꺼번에 처리합니다 (코드를 하나 골라 함께 쓰면 그 코드만).
- **선택**: 체크박스 / **☑ 전체 선택** 으로 고른 뒤 파란 막대에서 코드·빠르기·카테고리 일괄 지정, 확인 완료/되돌리기, 목록에서 제외(복원 가능), 파일 삭제(복구 불가).
- **도구 모음**(왼쪽 아래): 📁 폴더 다시 스캔 · 📂 폴더 바꾸기 · ⚙ 코드(Key) 설정 · ⚙ 빠르기(Speed) 설정 · ⚙ 카테고리(Tag) 설정 · ⬇ 엑셀(CSV) 내보내기 · 🧩 중복 곡 정리. 설정 버튼에서는 항목을 추가·이름 변경·삭제·순서 변경하고, 파일명 자동 인식 키워드를 정할 수 있습니다.
- **🧩 중복 곡 정리**: 제목(숫자 제외)과 코드가 같은 곡을 묶어 보여 주고, 하나만 남기고 나머지를 제외하거나 삭제합니다. 카테고리·메모·빠르기는 남기는 곡에 합쳐지고 콘티의 악보도 바뀝니다. 중복이 아니면 **중복 아님**으로 표시합니다.
- 카드 크기 슬라이더, 검색, 엑셀(CSV) 내보내기가 있습니다.

## 콘티 (찬양 콘티 · 인쇄 · JPG)
왼쪽 위 **📋 콘티** 탭에서 사용합니다.
- **📥 콘티 가져오기**: 저장소의 `contis.json` (2023~2026 콘티 261개, 1,377곡)을 불러옵니다. 한 번만 하면 됩니다.
- 콘티를 고르면 곡 순서·악보 파일(코드)을 바꾸고, **＋ 곡 추가**로 악보함에서 곡을 골라 넣을 수 있습니다. 곡마다 사용 횟수/마지막 사용일이 보입니다. 변경은 자동 저장됩니다.
- **🖨 인쇄 · JPG 만들기**: B4 / A3 / A4, 한 면 2칸(가로·양면) 또는 1칸(세로). 짧은 곡은 한 칸에 쌓이고, 후렴은 **자르기**로 일부만 넣고 빨간 라벨을 달 수 있습니다.
  - **🖨 인쇄**: 브라우저 인쇄 창에서 *여백 없음 · 배율 100% · 양면 인쇄*로 출력하세요.
  - **💾 JPG로 저장**: 악보 폴더의 `콘티출력` 폴더에 면마다 JPG 한 장씩 저장합니다 (악보 목록에는 나타나지 않음).
- 이미지 악보(jpg/png 등)만 배치할 수 있습니다. PDF 악보는 이미지로 변환해야 합니다.
